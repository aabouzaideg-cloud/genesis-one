## Code Changes Made This Session

### 1. Value Zone EMA Fix (`confluence_gate.py`)
- **Problem:** Polygon returns only 1 bar for GOLD/BTC — not enough to compute EMA21, so `ema = None` and value zone only checked Fib (too far from price). GOLD BUY blocked all morning.
- **Fix:** `_in_value_zone()` now accepts `hint_ema` parameter. `evaluate_scan()` passes `signal.ema21` (already computed by scanner from Capital.com 15m feed) as fallback when df has no EMA column.

### 2. Candle Geometry Fix (`confluence_gate.py`)
- **Problem:** `uw > 0.5 * body` was triggering on micro-body doji candles (e.g. body=0.30, uw=1.10). Meaningless ratio on tiny candles.
- **Fix:** Added minimum body threshold — wick check only applies when `body >= 0.3 * ATR`. Micro candles pass through; real rejection wicks still blocked.

### 3. Cooldown Split (`market_scanner.py`, `correlation_engine.py`)
- **Problem:** 4h cooldown fired immediately when signal was emitted — even if the gate blocked the trade. One bad candle silenced an epic for 4 hours.
- **Fix:** Split into two cooldowns:
  - `REFIRE_COOLDOWN = 45min` — prevents signal spam between scans
  - `SIGNAL_COOLDOWN = 4h` — only set after a trade is **approved and placed** (via `set_trade_cooldown()`)
- `core_engine.py` calls `scanner.set_trade_cooldown(epic, direction)` or `corr_engine.set_trade_cooldown(epic, direction)` after each approved scan trade.
